# Privacy Policy

Clipboard Drop is designed to keep clipboard text local to your Mac.

## Data Collection

Clipboard Drop does not collect, track, sell, or share personal data.

## Clipboard Content

Clipboard Drop reads text from the macOS clipboard only to prepare content that you choose to send with AirDrop.

Clipboard Drop does not upload clipboard content to a server, sync it through cloud storage, or run a receiving service.

## Clipboard History

Clipboard Drop does not save clipboard history to disk. Recent clipboard text may be kept in memory while the app is running so it can be shown in the menu bar popover. This in-memory data is cleared when the app quits.

## Temporary Files

When you send text or a link, Clipboard Drop writes a temporary `.txt`, `.md`, or URL file so macOS can hand it to AirDrop. Each file is deleted after the system sharing service reports success, failure, or cancellation. The temporary directory is also cleared when the app starts and quits.

## AirDrop

AirDrop delivery is handled by macOS. Clipboard Drop asks the system sharing service to send the temporary item, but it does not control the receiver device or Apple account behavior.
